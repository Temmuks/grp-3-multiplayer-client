# Snake Attack Client

## About
Snake Attack is built as an schoolproject to practice realtimeupdates using websockets. <br>
The game idea is that you will be a snake that leaves a trail behind you, other players should try to avoid colliding with you while your object is to get in front of them as much as possible!

## Features
* Create gameroom
* Join gameroom
* Steer your snake with keyboard
* Dash forward for some extra speed

## Installation
* Step 1: Make sure you got the server running
* Step 2: Copy env.example and name it .env
* Step 3: Edit .env to fit your setup
* Step 4: Open your terminal in the root folder.
* Step 5: Run `npm install`
* Step 6: Run `npm run dev`
* Step 7: Go to http://localhost:5173/
